# Horse farm real estate: website demo

Sample design for a Twin Cities horse farm real estate site, made to show the agents before the planning call.

- "Saddle & Section" is a placeholder brand. All farms, prices, phone numbers, and agents are placeholders, not real listings.
- Forms are not connected. The page is marked noindex so search engines skip it.
